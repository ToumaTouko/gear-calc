# 齿轮传动设计计算工具

标准渐开线**直齿圆柱齿轮**的几何计算与强度校核工具。单文件、纯前端、双击即用，所有公式均按《机械设计》（第 11 版）教材逐条核对。

![界面截图](screenshot.png)

## 这个工具解决什么问题

机械设计课程设计里，齿轮传动的计算要反复查表、插值、套公式、验算，改一个参数就得把整条链重算一遍。手算一版动辄一两个小时，而且中间任何一步抄错，后面的结果全废。

这个工具把这套流程自动化，并且**把每一步的公式和结果并排展示**——你能看到的不是"一个答案"，而是"答案是怎么来的"。

## 功能

**① 基本参数输入**
模数 `m`、齿数 `z₁`/`z₂`、压力角 `α`、齿宽系数 `φd`、小齿轮转矩 `T₁`

**② 几何尺寸计算（10 项自动）**
传动比 `i`、分度圆 `d₁`/`d₂`、齿顶圆 `dₐ`、齿根圆 `d_f`、全齿高 `h`、标准中心距 `a`、齿宽 `b`

**③ 强度校核**

| 计算项 | 依据 |
|---|---|
| 齿形系数 `Y_Fa`、应力修正系数 `Y_Sa` | 按**表 10-5** 自动查表 + 线性插值，随齿数实时更新 |
| 弹性影响系数 `Z_E` | **表 10-6** 下拉选择（锻钢-锻钢等配对） |
| 区域系数 `Z_H` | **式 (10-9)** 自动计算 `√(2/(cosα·sinα))` |
| 重合度系数 `Z_ε` | **式 (10-9)** 自动计算 `√((4−ε_α)/3)` |
| 弯曲强度重合度系数 `Y_ε` | **式 (10-5)** 自动计算 `0.25 + 0.75/ε_α` |
| 齿面接触应力 `σ_H` | **式 (10-10)** |
| 齿根弯曲应力 `σ_F` | **式 (10-6)** |
| 所需最小模数 `m_min` | **式 (10-7)** 反算 |
| 所需最小分度圆直径 `d₁min` | **式 (10-11)** 反算 |

**④ 一键导出计算书**——生成的页面可直接打印或存为 PDF，格式可作课程设计计算书附录。

### 教材依据

- **《机械设计》（第 11 版）**——西北工业大学机械原理及机械零件教研室 编著，濮良贵、陈国定、吴立言、宁方立 主编，高等教育出版社，2024。
  界面中标注的「式 (10-x)」「表 10-x」编号均指该书**第 10 章 齿轮传动**。
- **《机械原理》（第 9 版）**——西北工业大学机械原理与机械零件教研室 编著，孙桓、葛文杰 主编，高等教育出版社，2021。
  端面重合度 `ε_α` 等齿轮啮合参数的参考依据；`ε_α` 在本工具中由使用者手工填入，未做自动计算。

两本书的编著单位都是西北工业大学，这也是「西工大版」这一俗称的由来——但出版方是高等教育出版社。

默认参数（m=3, z₁=20, z₂=60, α=20°, φd=1.0, T₁=50000 N·mm, ε_α=1.7）下，工具输出与手工复算一致：

| 结果 | 数值 |
|---|---|
| 齿面接触应力 σ_H | 356.8 MPa |
| 齿根弯曲应力 σ_F | 33.3 MPa |
| 所需最小模数 m_min | 1.41 mm |
| 所需最小分度圆直径 d₁min | 42.43 mm |

## 关于开发方式

这个项目**不是纯手工写的代码，也不是纯 AI 生成的**，边界很清楚：

- **由我负责**：公式的选取、计算逻辑的设计、参数的取值范围、结果的验收。全部公式对照《机械设计》教材逐条核对，默认参数下的四个结果用计算器手工复算验证一致。
- **由 AI 辅助**：HTML 界面和 JavaScript 代码的编写。

换句话说——**工程判断是我的，代码是打字的部分由 AI 加速完成。**

这样说明不是免责，是想说清楚一件事：工具里每一个公式为什么长这样，我都能解释。

## 已知限制

- **端面重合度 `ε_α` 需手工填入**（默认 1.7），工具不做自动计算——`ε_α` 由齿顶圆压力角等啮合参数导出，属《机械原理》内容；本工具只实现《机械设计》第 10 章的几何与强度计算。填入后 `Z_ε`（式 10-9）与 `Y_ε`（式 10-5）会自动算出。
- 目前仅支持**标准渐开线直齿圆柱齿轮**，不含斜齿轮、变位齿轮、锥齿轮。
- `σ_Hlim` / `σ_Flim`（接触/弯曲疲劳极限）需按材料与热处理方式查手册后手工填入。
